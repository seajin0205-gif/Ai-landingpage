Key Learnings

  • AI UX에서는 기능보다 반복 수정 경험이 더 중요합니다. 생성만 잘 되는 것보다 같은 맥락에서 고치고 비교하는 루프가 제품 가치를 결정합니다.
  • 하나의 Workspace 안에서 작업 흐름을 유지하는 것이 UX를 크게 향상시킵니다. UI 통합은 '기능 합치기'가 아니라 맥락 유지가 목적입니다.
  • UI보다 사용자의 작업 흐름을 먼저 설계하는 것이 중요했습니다. Intent → Export 순서가 모든 화면 구조의 기준이 되었습니다.
  • 생성 이후의 수정 경험까지 고려해야 완성도 높은 AI 제품이 됩니다. Result Panel, Variant 비교, Export까지 한 화면에 두는 것이 핵심 설계 결정이었습니다.

Project Summary

사용자 Pain Point 분석 → Workspace UX 설계 → Design System → 구현.
화면을 만든 것이 아니라, AI 작업 흐름을 재설계한 프로젝트입니다.
